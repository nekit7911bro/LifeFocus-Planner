# LifeFocus Planner

## О проекте

**LifeFocus Planner** – веб-приложение для создания и управления задачами. Приложение разработано на Python с использованием Flask, PostgreSQL, HTML и CSS.

Основные возможности:
- Создание, редактирование и удаление задач.
- Установка сроков выполнения и изменение статусов.
- Поиск задач по названию, фильтрация и сортировка.
- Разделение задач по категориям.
- Просмотр календаря и статистики.
- Переключение светлой и тёмной темы.
- Регистрация и авторизация пользователей.

## Запуск на компьютере

### 1. Требования

Установите Python, PostgreSQL и pgAdmin 4.

### 2. Подготовка базы данных

1. Запустите PostgreSQL и откройте pgAdmin 4.
2. Создайте базу данных `lifefocus_db`.
3. Откройте Query Tool для этой базы данных.
4. Откройте файл `database/lifefocus_db.sql`, скопируйте SQL-код и выполните его.
5. Убедитесь, что таблицы и категории созданы.

### 3. Установка зависимостей

Откройте терминал в папке проекта и выполните команды:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если виртуальное окружение уже создано, повторно создавать его не нужно.

### 4. Настройка подключения к базе данных

В `main.py` используются параметры подключения к PostgreSQL. По умолчанию имя базы данных – `lifefocus_db`, пользователь – `postgres`, адрес – `localhost`, порт – `5432`.

Если для пользователя PostgreSQL установлен пароль, задайте его в PowerShell перед запуском:

```powershell
$env:DB_PASSWORD="ваш_пароль"
```

### 5. Запуск приложения

Выполните команду:

```powershell
python main.py
```

Откройте браузер на компьютере и перейдите по адресу:

`http://127.0.0.1:5000`

## Запуск на телефоне

Приложение можно проверить на телефоне через локальную сеть Wi-Fi без публикации в интернете.

1. Убедитесь, что в конце `main.py` используется следующий запуск Flask:

```python
if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000, debug=True)
```

2. Подключите компьютер и телефон к одной сети Wi-Fi.
3. Запустите приложение командой `python main.py`.
4. Откройте PowerShell на компьютере и выполните:

```powershell
ipconfig
```

5. Найдите IPv4-адрес адаптера Wi-Fi.
6. В браузере телефона введите адрес в формате:

`http://IP-АДРЕС:5000`

Например, если IPv4-адрес компьютера `192.168.1.105`, используйте `http://192.168.1.105:5000`.

Если подключение блокируется брандмауэром Windows, разрешите доступ для частной сети.

**Важно:** компьютер, PostgreSQL и Flask должны оставаться включёнными. Для проверки на телефоне не используйте этот отладочный сервер в открытом интернете.
