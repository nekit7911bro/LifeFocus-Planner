
# LifeFocus Planner

**LifeFocus Planner** — веб-приложение для планирования учебных задач,
рабочих дел, спортивных занятий и личных планов.

## Возможности

- Регистрация и авторизация пользователей.
- Создание, редактирование и удаление задач.
- Изменение статуса выполнения задачи.
- Установка сроков выполнения.
- Поиск задач по названию.
- Фильтрация по статусу и категории.
- Сортировка задач по дате и алфавиту (А–Я, Я–А).
- Календарь запланированных задач.
- Статистика выполнения задач.
- Светлая и тёмная темы оформления.

## Технологии

- Python
- Flask
- PostgreSQL
- HTML5
- CSS3
- pgAdmin 4 для управления базой данных

## Структура проекта

- `main.py` — серверная логика и маршруты Flask.
- `templates/` — HTML-шаблоны приложения.
- `static/css/` — стили страниц.
- `database/lifefocus_db.sql` — SQL-скрипт создания таблиц,
  связей, индекса и начальных категорий.
- `requirements.txt` — зависимости Python.
- `.gitignore` — файлы, исключённые из Git.

## Требования

- Установленный Python.
- Установленный PostgreSQL.
- pgAdmin 4 для удобного управления базой данных.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd LifeFocus_Planner
```

### 2. Создание виртуального окружения

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Создание базы данных

В pgAdmin 4 создай базу данных с именем `lifefocus_db`.

Открой Query Tool именно для этой базы и выполни SQL-скрипт
`database/lifefocus_db.sql`.

Скрипт создаёт необходимые таблицы, связи, индекс и начальные категории.

### 5. Настройка подключения

В PowerShell укажи пароль пользователя PostgreSQL:

```powershell
$env:DB_PASSWORD="ТВОЙ_ПАРОЛЬ_POSTGRES"
$env:SECRET_KEY="ТВОЙ_СЕКРЕТНЫЙ_КЛЮЧ"
```

Используй собственные значения. Не публикуй реальные пароли
и секретные ключи в репозитории.

### 6. Запуск приложения

```powershell
python main.py
```

После запуска открой адрес, указанный Flask в терминале,
обычно `http://127.0.0.1:5000`.

## База данных

В проекте используются таблицы:

- `users` — данные пользователей и хеши паролей.
- `categories` — категории задач.
- `tasks` — задачи, сроки, статусы и связи с пользователями.

Начальные категории: Учёба, Спорт, Работа, Личное и Другое.

## Примечание

SQL-файл в репозитории предназначен для создания структуры базы
и начальных категорий. Он не содержит резервную копию личных
данных пользователей.
