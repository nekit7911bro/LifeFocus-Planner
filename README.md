# LifeFocus Planner

## О проекте

**LifeFocus Planner** — веб-приложение для планирования и управления задачами. Проект разработан с использованием Python, Flask, PostgreSQL, HTML и CSS.

Основные возможности:
- Регистрация и авторизация пользователей.
- Создание, редактирование и удаление задач.
- Установка сроков выполнения и изменение статусов.
- Поиск задач по названию, фильтрация и сортировка.
- Разделение задач по категориям.
- Просмотр календаря и статистики.
- Переключение светлой и тёмной темы.

## Запуск на компьютере

### 1. Необходимые программы

Для запуска проекта необходимы:
- Python;
- Git;
- PostgreSQL;
- pgAdmin 4 для управления базой данных.

### 2. Клонирование репозитория

Откройте PowerShell в папке, в которой хотите разместить проект, и выполните:

```powershell
git clone https://github.com/nekit7911bro/LifeFocus-Planner.git
cd LifeFocus-Planner
```

### 3. Создание виртуального окружения

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

### 4. Активация виртуального окружения

**Способ 1. Через PowerShell**

Выполните команду:

```powershell
.\.venv\Scripts\Activate.ps1
```

Если появилось сообщение о запрете выполнения сценариев, выполните:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Если PowerShell запросит подтверждение, введите `Y` и нажмите Enter. Затем повторите команду активации:

```powershell
.\.venv\Scripts\Activate.ps1
```

Данная настройка действует только в текущем окне PowerShell. После его закрытия она перестанет действовать.

**Способ 2. Через командную строку Windows (cmd)**

Если не хотите менять настройки PowerShell, откройте терминал `cmd` в папке проекта и выполните:

```cmd
.venv\Scripts\activate.bat
```

После успешной активации в начале строки терминала появится `(.venv)`.

### 5. Установка зависимостей

При активированном виртуальном окружении выполните:

```powershell
python -m pip install -r requirements.txt
```

### 6. Настройка базы данных

1. Запустите PostgreSQL и откройте pgAdmin 4.
2. Создайте базу данных с именем `lifefocus_db`.
3. Откройте Query Tool для этой базы данных.
4. Откройте SQL-файл `database/lifefocus_db.sql`.
5. Выполните SQL-скрипт для создания таблиц и добавления основных категорий.
6. Проверьте параметры подключения к PostgreSQL в `main.py`. При необходимости укажите собственные адрес, порт, имя базы данных, пользователя и пароль.

Если SQL-файл расположен в другом месте репозитория, используйте фактический путь к нему.

### 7. Запуск приложения

Убедитесь, что виртуальное окружение активировано, а PostgreSQL запущен. Затем выполните:

```powershell
python main.py
```

Откройте браузер на компьютере и перейдите по адресу:

`http://127.0.0.1:5000`

## Проверка на телефоне

Приложение можно открыть на телефоне через локальную сеть Wi-Fi без публикации в интернете.

1. Подключите компьютер и телефон к одной сети Wi-Fi.
2. Убедитесь, что Flask запускается с параметрами `host="0.0.0.0"` и `port=5000`.
3. Запустите приложение командой `python main.py`.
4. На компьютере выполните в PowerShell:

```powershell
ipconfig
```

5. Найдите IPv4-адрес адаптера Wi-Fi.
6. Откройте браузер на телефоне и введите адрес в формате `http://IP-АДРЕС:5000`, заменив `IP-АДРЕС` на фактический адрес компьютера.

Например, для адреса `192.168.1.105` используйте `http://192.168.1.105:5000`.

Если подключение блокируется брандмауэром Windows, разрешите доступ для частной сети.

**Важно:** компьютер, PostgreSQL и Flask должны оставаться включёнными. Отладочный сервер предназначен для локальной проверки и не должен использоваться для публичного размещения приложения в интернете.
