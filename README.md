# LifeFocus Planner

## О проекте

**LifeFocus Planner** — веб-приложение для планирования и управления задачами. Проект разработан на Python с использованием Flask, PostgreSQL, HTML и CSS.

Основные возможности:
- Регистрация и авторизация пользователей.
- Создание, редактирование и удаление задач.
- Установка сроков выполнения и изменение статусов.
- Поиск задач по названию, фильтрация и сортировка.
- Категории задач: учёба, спорт, работа, личное и другое.
- Календарь и статистика задач.
- Переключение светлой и тёмной темы.

## Запуск на компьютере

### 1. Необходимые программы

Установите Python, Git и PostgreSQL. Для управления базой данных рекомендуется использовать pgAdmin 4.

### 2. Клонирование репозитория

Откройте PowerShell в папке, куда хотите скачать проект, и выполните:

```powershell
git clone https://github.com/nekit7911bro/LifeFocus-Planner.git
cd LifeFocus-Planner
```

### 3. Создание виртуального окружения

```powershell
python -m venv .venv
```

### 4. Активация виртуального окружения

В PowerShell выполните:

```powershell
.\.venv\Scripts\Activate.ps1
```

Если Windows запрещает выполнение сценариев, выполните:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Если появится запрос подтверждения, введите `Y` и нажмите Enter. Затем повторите команду активации:

```powershell
.\.venv\Scripts\Activate.ps1
```

Если не хотите менять настройки PowerShell, можно открыть командную строку Windows (`cmd`) и выполнить:

```cmd
.venv\Scripts\activate.bat
```

После активации в начале строки терминала должно появиться `(.venv)`.

### 5. Установка зависимостей

При активированном виртуальном окружении выполните:

```powershell
python -m pip install -r requirements.txt
```

### 6. Создание и настройка базы данных

1. Запустите PostgreSQL и откройте pgAdmin 4.
2. Создайте базу данных `lifefocus_db`.
3. Откройте Query Tool для этой базы данных.
4. Найдите SQL-файл `lifefocus_db.sql` в проекте и выполните его. Если файл находится в папке `database`, используйте путь `database/lifefocus_db.sql`.
5. Убедитесь, что созданы таблицы `users`, `categories` и `tasks`, а также добавлены основные категории.

### 7. Настройка подключения к PostgreSQL

**Перед запуском приложения необходимо указать параметры подключения к своей базе данных.**

В том же окне PowerShell, где активировано виртуальное окружение, выполните:

```powershell
$env:DB_HOST = "localhost"
$env:DB_PORT = "5432"
$env:DB_NAME = "lifefocus_db"
$env:DB_USER = "postgres"
$env:DB_PASSWORD = 'ВАШ_ПАРОЛЬ_POSTGRES'
```

Замените `ВАШ_ПАРОЛЬ_POSTGRES` на пароль пользователя PostgreSQL.

Параметр `DB_NAME` должен совпадать с именем базы данных, в которой созданы таблицы. Например, если вы используете базу `testik`, укажите:

```powershell
$env:DB_NAME = "testik"
```

Если используется другая база данных, укажите её фактическое имя. Остальные параметры также можно изменить при необходимости.

**Важно:** переменные окружения действуют в текущем окне PowerShell. При открытии нового терминала их необходимо задать повторно. Не сохраняйте свой пароль PostgreSQL в репозитории или README.

### 8. Запуск приложения

Убедитесь, что PostgreSQL запущен, а виртуальное окружение активировано. Затем выполните:

```powershell
python main.py
```

Откройте браузер на компьютере и перейдите по адресу:

`http://127.0.0.1:5000`

Для остановки сервера нажмите `Ctrl + C` в терминале.

## Проверка на телефоне

Приложение можно открыть на телефоне через локальную сеть Wi-Fi без размещения на хостинге.

1. Подключите компьютер и телефон к одной сети Wi-Fi.
2. Убедитесь, что приложение запускается с параметрами Flask `host="0.0.0.0"` и `port=5000`.
3. Запустите приложение на компьютере командой `python main.py`.
4. Откройте PowerShell и выполните:

```powershell
ipconfig
```

5. Найдите IPv4-адрес адаптера Wi-Fi.
6. Откройте браузер на телефоне и введите адрес в формате `http://IP-АДРЕС:5000`, заменив `IP-АДРЕС` на фактический адрес компьютера.

Например, если IPv4-адрес компьютера `192.168.1.102`, используйте:

`http://192.168.1.102:5000`

Если подключение блокируется брандмауэром Windows, разрешите доступ для частной сети.

**Важно:** компьютер, PostgreSQL и Flask должны оставаться включёнными. Отладочный сервер предназначен для локальной проверки и не должен использоваться для публичного размещения приложения в интернете.
