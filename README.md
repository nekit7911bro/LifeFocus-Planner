# LifeFocus Planner

## О проекте

**LifeFocus Planner** — веб-приложение для планирования и управления задачами. Проект разработан с использованием Python, Flask, PostgreSQL, HTML и CSS.

Основные возможности:
- Регистрация и авторизация пользователей.
- Создание, редактирование и удаление задач.
- Установка сроков выполнения и изменение статусов.
- Поиск задач по названию, фильтрация и сортировка.
- Разделение задач по категориям.
- Просмотр календаря и статистики.
- Переключение светлой и тёмной темы.

## Запуск на компьютере

### 1. Требования

Установите Python, Git и PostgreSQL. Для управления базой данных можно использовать pgAdmin 4.

### 2. Клонирование репозитория

Откройте PowerShell в папке, в которой хотите разместить проект, и выполните:

```powershell
git clone https://github.com/nekit7911bro/LifeFocus-Planner.git
cd LifeFocus-Planner
```

После клонирования все файлы проекта появятся в папке `LifeFocus-Planner`.

### 3. Создание виртуального окружения и установка зависимостей

В терминале внутри папки проекта выполните:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если PowerShell сообщает об ошибке при активации окружения, проверьте настройки выполнения сценариев в соответствии с документацией PowerShell.

### 4. Настройка базы данных

1. Запустите PostgreSQL и откройте pgAdmin 4.
2. Создайте базу данных с именем `lifefocus_db`.
3. Откройте Query Tool для этой базы данных.
4. Откройте SQL-файл `lifefocus_db.sql` в папке проекта.
5. Выполните SQL-скрипт, чтобы создать таблицы и добавить основные категории.
6. Проверьте параметры подключения к PostgreSQL в `main.py`. При необходимости укажите данные своей локальной базы: адрес, порт, имя базы, пользователя и пароль.

### 5. Запуск приложения

При активированном виртуальном окружении выполните:

```powershell
python main.py
```

Откройте браузер и перейдите по адресу:

`http://127.0.0.1:5000`

## Проверка на телефоне

Приложение можно открыть на телефоне через локальную сеть Wi-Fi без публикации в интернете.

1. Подключите компьютер и телефон к одной сети Wi-Fi.
2. Убедитесь, что Flask запускается с параметрами `host="0.0.0.0"` и `port=5000`.
3. Запустите приложение командой `python main.py`.
4. На компьютере откройте PowerShell и выполните:

```powershell
ipconfig
```

5. Найдите IPv4-адрес адаптера Wi-Fi.
6. Введите в браузере телефона адрес в формате `http://IP-АДРЕС:5000`, заменив `IP-АДРЕС` на фактический адрес компьютера.

Например, если IPv4-адрес компьютера `192.168.1.105`, откройте `http://192.168.1.105:5000`.

Если соединение блокируется брандмауэром Windows, разрешите доступ для частной сети.

**Важно:** компьютер, PostgreSQL и Flask должны оставаться включёнными. Отладочный сервер предназначен для локальной проверки и не должен использоваться для публичного размещения приложения в интернете.
